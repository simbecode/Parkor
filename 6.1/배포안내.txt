Parkor Analyzer 6.2
===================

중요: 폴더형(onedir) 프로그램입니다
---------------------------------
이 배포본은 빠른 실행을 위한 폴더형 프로그램입니다.
ParkorAnalyzer.exe만 따로 복사하거나 이동하면 실행되지 않습니다.

반드시 다음 항목을 같은 폴더에 유지하세요.

ParkorAnalyzer-6.2-onedir\
├─ ParkorAnalyzer.exe
├─ _internal\
├─ 배포안내.txt
└─ SHA256SUMS.txt

- 프로그램을 옮길 때는 상위 폴더 전체를 이동하세요.
- _internal 폴더의 이름을 바꾸거나 내부 파일을 삭제하지 마세요.
- 바탕화면에서 실행하려면 EXE를 복사하지 말고 바로가기를 만드세요.
- ZIP 파일 내부에서 직접 실행하지 말고 먼저 완전히 압축 해제하세요.

폴더형 배포의 장점
-----------------
- 실행할 때 대용량 라이브러리를 매번 풀지 않아 단일 EXE보다 빠르게 시작됩니다.
- 백신이 매번 전체 압축을 검사하는 시간이 줄어들 수 있습니다.
- 프로그램 구성 파일이 분리되어 실행 문제를 확인하기 쉽습니다.

실행 방법
---------
1. ZIP 파일을 원하는 위치에 완전히 압축 해제합니다.
2. 압축 해제된 폴더 안의 ParkorAnalyzer.exe를 실행합니다.
3. _internal 폴더는 실행에 필요하므로 이동하거나 삭제하지 마세요.
4. Windows SmartScreen 경고가 표시되면 파일 출처를 확인한 뒤 실행합니다.
5. 프로그램 시작 시 선택된 관측소의 당일 데이터를 자동으로 수집합니다.

주요 기능
---------
- 조회 이력 없음, 누락 데이터, 제로값, 통합 센서 문제, 음수 차이값 탐지
- 결과 더블클릭 시 판정 조건에 해당하는 원본 데이터 표시
- 연동 사이트에서 해당 관측소와 날짜 자동 조회
- 설정 메뉴에서 관측소와 판정 임계값 변경

사용 환경
---------
- Windows 10/11 64비트
- 인터넷 연결 필요
- 별도의 Python 설치 불필요
- ParkorAnalyzer.exe와 _internal 폴더를 항상 같은 위치에 유지

설정 저장 위치
-------------
관측소 및 판정 설정은 Windows 사용자별 설정 저장소에 보관됩니다.
프로그램 폴더에는 별도의 설정 파일을 만들지 않습니다.

바탕화면 바로가기 만들기
-----------------------
1. ParkorAnalyzer.exe를 마우스 오른쪽 버튼으로 클릭합니다.
2. 더 많은 옵션 표시 > 보내기 > 바탕 화면에 바로 가기 만들기를 선택합니다.
3. 만들어진 바로가기를 통해 실행합니다.

업데이트 방법
-------------
1. 실행 중인 Parkor Analyzer를 종료합니다.
2. 새 버전 ZIP을 별도의 폴더에 완전히 압축 해제합니다.
3. 새 폴더의 ParkorAnalyzer.exe를 실행합니다.
4. 설정은 Windows 사용자 설정에 저장되므로 같은 사용자라면 유지됩니다.

문제 해결
---------
- 데이터가 나오지 않으면 인터넷 연결과 공식 측정데이터 사이트 상태를 확인하세요.
- 연동 사이트 창은 Esc 키로 닫을 수 있습니다.
- 백신이 실행 파일을 검사하는 동안 첫 실행이 느릴 수 있습니다.

무결성 확인
-----------
SHA256SUMS.txt의 SHA-256 값과 실행 파일의 해시가 일치하는지 확인할 수 있습니다.
